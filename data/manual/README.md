# 손으로 옮긴 검색창 조각

웹페이지(`scripts/urls.txt`)로 모을 수 없는 **학교 공식 문서**의 내용을 조각으로 옮겨 둔 곳입니다.
`npm run collect`가 웹페이지 조각 뒤에 이 폴더의 `*.json`을 그대로 붙여 `data/chunks.json`을 만듭니다. 그다음 `npm run ingest`(AI 담당만 실행)로 DB에 들어갑니다.

## 규칙

- 조각 형식은 `data/chunks.json`과 같습니다: `id`, `title`, `url`, `section`, `text`, `collected_at` (다른 칸을 넣으면 ingest가 실패할 수 있음)
- `id`는 파일마다 고유한 앞글자를 씁니다(예: `guide2026-01`). 웹페이지 조각 id(`11371-01` 같은 숫자)와 겹치지 않게 합니다.
- `text` 첫 줄은 `[문서 이름 > 구역]`. 원문 숫자·날짜·조건은 바꾸지 않고 옮깁니다.
- **서울캠퍼스 내용만** 넣습니다. 글로벌캠퍼스 내용이나 캠퍼스 표기가 없어 어느 캠퍼스 것인지 분명하지 않은 내용은 넣지 않습니다.
- 전화번호 · 이메일 · 담당자 이름은 넣지 않습니다.
