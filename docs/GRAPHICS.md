## 2. 좌표계 · 맵 크기

### 2-1. 공식 좌표 → 타일

HUFS MAP 건물 좌표(기준점 37.5975, 127.0585에서 잰 미터, E=동쪽+, N=북쪽+)를 아래 식으로 타일로 바꿉니다. 건물 **위치**는 이 좌표, **모양 · 크기**는 위성 사진을 따릅니다.

```
타일 x = (E + 152) / 4      // 맵 왼쪽 끝 = E −152m (이문로9길 바깥)
타일 y = (128 − N) / 4      // 맵 위쪽 끝 = N +128m (북쪽 길 바깥)
```

- 위성 사진 ↔ 공식 좌표 맞춤: `E = 0.3155·px − 164`, `N = −0.298·py + 134.8` (건물 14곳으로 최소제곱. 차이 2~16m — 좌표가 건물 정중앙이 아니라 지도 표시 위치라서 생기는 차이)
- 검증 규칙: **각 건물의 공식 좌표 점이 그 건물 타일 안에 들어가야 합니다.** 지금 제안은 17개 건물 모두 통과(Minerva Square만 1칸 옆, 열린 공간이라 허용).

### 2-2. 왜 84×84가 아니라 88×90인가

| 방향 | 꼭 들어가야 하는 것 | 필요한 길이 | 84타일(336m)이면 |
| --- | --- | --- | --- |
| 동서 | 서쪽 이문로9길(E −150 안팎) ~ 출판부 동쪽 벽(E +189 + 건물 폭) | 약 350m → 88타일 | 이문로9길이나 출판부가 잘림 |
| 남북 | 북쪽 길(N +125 안팎) ~ 교수연구동 남쪽 벽(N −220 − 건물 깊이) | 약 360m → 90타일 | 북쪽 길이나 교수연구동이 잘림 |

### 2-3. 모바일 성능 영향 (80×72 → 88×90)

- 타일 수: 레이어당 5,760 → 7,920칸(**+37%**). Phaser 타일맵은 화면에 보이는 칸(약 60×34)만 그리므로 **한 프레임에 그리는 양은 그대로**입니다.
- 늘어나는 것: 타일 객체 메모리(레이어 2개 × 7,920칸, 수 MB 수준), 시작할 때 `buildCampusLayers()` 두 번(장면 · 전체 지도), 퀴즈 상자 BFS(걷는 칸 약 3,000개) — 모두 체감하기 어려운 수준.
- 화면 조정이 필요한 것: 전체 지도(M) `SCALE 6`이면 528×540px로 패널을 넘침 → **`SCALE 5`(440×450px)** 로 바꾸고 `MAP.y`를 조금 올림. 미니맵은 160×144 → 176×180px.
- 걷는 시간: 정문(SPAWN)에서 가장 먼 인문과학관까지 길로 약 100타일 ≈ 18초(속도 90px/s).

## 5. 건물 표현

### 5-1. 데이터 형식(2단계에서 확장)

```js
// 건물 id는 그대로. parts는 [x, y, w, h] 타일 사각형 1~4개, door는 입구 칸과 바라보는 방향
{ id: "main", parts: [[9, 27, 18, 5], [21, 32, 7, 8], [10, 42, 18, 5]], door: { x: 24, y: 39, face: "S" },
  roof: "GRAY", height: "high" }
```

- `doorTile(building)`은 `building.door`를 돌려줍니다. NPC는 입구 앞 칸의 옆에 세워 길을 막지 않습니다.
- 겹침 금지는 **다른 건물끼리**만. 한 건물의 parts끼리는 맞닿거나 겹쳐도 됩니다.
- **지하 건물**(`underground: true`, 지금은 Minerva Complex · 오바마홀만): 지상에는 유리 천창 줄(걷기 불가)과 둘레 포장면만 그리고, 벽 · 창문 · 옥상 없이 **입구(내려가는 계단) 1칸**만 둡니다.
- **지도에 없는 장소**: `buildingInfo.js`에서 지우지 않고 `onMap: false`를 붙입니다(지금은 휴게공간 오디 `rest`만). `campus.js`와의 id 일치 테스트는 이 표시가 있는 항목만 예외로 둡니다.

### 5-2. 지붕 · 벽 · 높이

- 위에서 내려다본 옥상이 기본입니다. 각 사각형의 **남쪽 끝 줄**에만 벽(24)과 창문(21·22)을 그려 높이를 보여 줍니다.
- 높이는 공식 층수 자료를 확인하기 전까지 숫자로 쓰지 않고, 위성 사진 그림자 길이로 **3단계만** 표현합니다: 낮음 = 벽 1줄, 중간 = 벽 2줄, 높음 = 벽 3줄.
- 옥상 테두리 1px는 같은 계열 어두운 색(17 · 20), 옥상 설비 · 난간은 20, 태양광은 21 바탕에 22로 칸 줄.

3. 본관 — 질문 입력창 NPC
4. 도서관 — 남쪽 가운데 큰 건물, 태양광 지붕이 눈에 띔
5. 외국어연수평가원 — 두 번째 퀘스트 목적지(시간이 모자라면 옥상 색만)

동선 밖 건물은 3단계에서 옥상 색만 팔레트로 바꾸고 외관(창문 줄 · 설비)은 지금 그림 수준으로 둡니다.
