# NCP 사용 숫자 (발표용)

**목적:** 발표 PPT의 NCP 구성도 · 사용량 장표에 쓸 숫자의 원본입니다. PPT의 숫자는 이 문서에서만 옮깁니다.

- **담당:** 종합 신중혁 · 공지 흐름 숫자 임현규 · PPT 옮기기 이종헌
- **마감:** 12/3
- **규칙:** 숫자는 결과 파일 · 콘솔 캡처 · PR 기록 등 출처가 있는 것만 적고, 출처를 같은 줄에 둡니다. 아직 없는 숫자는 "(담당 · 날짜) 채울 예정"으로 둡니다. 숨긴 eval 문항 점수는 이 문서에 쓰지 않습니다.
