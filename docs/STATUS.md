## 3. 전환 전까지 지킬 것 (AI 포함 모두)

- `npm run ingest`는 **기본 대상이 실서비스 `chunks`**다. 시험 DB에 넣을 때만 `npm run ingest -- --target next`. 첫 줄 띠에 대상 테이블이 크게 찍히니 반드시 확인한다. 실서비스 ingest는 11/21 전환 때 종헌만 한다.
- Supabase `chunks_next` 테이블 · `match_chunks_next` 함수, Vercel의 Preview 환경 변수 `CHUNKS_RPC`를 **지우거나 바꾸지 않는다.**
- PR Preview의 검색창은 시험 DB 기준이다. 검색창과 관계없는 PR도 Preview 검색 결과가 실서비스와 다를 수 있다.
- #43은 Merge하지 않는다.
- `scripts/eval.mjs`의 문항을 바꾸지 않는다(11/21 기준선과 비교본이 같은 62문항이어야 한다).
