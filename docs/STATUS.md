## 3. 전환 뒤 지킬 것 (AI 포함 모두)

- `npm run ingest`의 기본 대상은 실서비스 `chunks`다. 실행 전에 단톡에 알리고, 첫 줄 띠의 대상 테이블을 확인하고, 실행 사실과 조각 수 변화를 PR에 적는다. 시험할 때만 `--target next`.
- ingest가 끊기면(11/21~ 재시도 3번 뒤에도 실패) "중단: …번째 조각(id …)" 줄이 남고 옛 조각은 지우지 않는다. 같은 명령을 처음부터 다시 실행하면 된다. 실행 중 PC가 잠들지 않게 한다.
- `api/ask.js` 지시문 · 검색 설정을 바꾸면 eval을 다시 돌리고, 기준선(4장)보다 떨어지면 반영하지 않는다.
- eval은 이제 **63문항**(학사 48 · 범위 밖 3 · 까다로운 12, #45). 11/21 이전 결과(62문항)와 총점을 바로 비교하지 않는다.
