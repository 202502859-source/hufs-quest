- 대상 서비스: https://hufs-quest.vercel.app

## 1. 분류 기준

- **A**: 로그인 없이 열람할 수 있고, 확인한 robots.txt 규칙에서 해당 URL의 자동 수집 제한이 발견되지 않은 공개 안내 페이지. 이는 저작권·재이용 허가를 의미하지 않음.
- **B**: 로그인 없이 열람할 수 있지만, robots.txt 규칙에 의해 자동 수집이 제한되는 게시판 공지 또는 첨부자료. 승인 전 자동 수집·검색 DB 반영하지 않음.
- **C**: 로그인 등 인증이 필요한 학사정보시스템. 11/25 공식 Open API 존재 여부 및 이용 절차 신규 문의. 실제 연동은 본선 개발 범위에서 제외.

## 3. 기존 검색 평가와 관련된 필요성

2026-11-19 평가 결과는 학사 질문 45개 중 43개 정확, 범위 밖 질문 5개 중 5개 거절이었습니다. `이중전공 배정 기준이 뭐야?`에서는 생성 답변의 자리표시 및 핵심 조건 누락이 있었고, `2025학번 졸업하려면 몇 학점 필요해?`에서는 예외 적용 집단 설명과 평가의 금지어 조건이 충돌했습니다. 두 문제를 자료 부재로 단정하지 않으며 원문과 평가 기준을 함께 확인할 예정입니다.

학사일정 자료는 기존 범위 밖 문항인 `2027년 1학기 개강일` 및 `이번 학기 중간고사 기간` 등에 대한 근거 확장 후보입니다.

## 4. 학교에 요청할 사항

1. 본 목록의 학교 공식 공개 문서, 특히 B로 구분한 게시판 공지 및 첨부파일을 팀원이 **직접 내려받아** 비영리 대회 출품작 HUFS Quest의 검색 근거로 저장·활용할 수 있는지 확인 요청
2. 출처·원문 링크 표기, 문서 개정 시 재반영, 대회 종료 후 보존/삭제 등 필요한 활용 조건 안내 요청
3. 직접 활용이 불가능하면 공식 파일 제공이나 별도 승인 절차 안내 요청
4. 종합정보시스템에 외부 서비스용 공식 Open API가 있는지 및 이용 문의 창구 안내 요청 (11/25 별도 문의 발송, 현 단계에서 연동하지 않음)

**운영 원칙:** 비공개 자료나 개인정보는 수집하지 않습니다. 승인 전 B 자료의 첨부파일을 자동 수집하거나 검색 DB에 반영하지 않습니다. A 분류는 콘텐츠 재이용 승인을 의미하지 않습니다.
