## 3. 예비비 계산

현금 지출 = Claude 구독 223,300원 + 그래픽 도구 2종(Aseprite · PixelLab) 약 70,000원 + 베타 사례 60,000원 (+ Supabase Pro 39,900원).

| 경우 | 지출 합계 | 남는 현금(예비비) |
| --- | --- | --- |
| Supabase Pro **안 함** | 223,300 + 70,000 + 60,000 = 353,300원 | **102,700원** |
| Supabase Pro **함** | 353,300 + 39,900 = 393,200원 | **62,800원** |
| (참고) 환율·수수료 5% 더 나올 때(Pro 함) | 약 412,900원 | 약 43,100원 |

- **예비비 20만 원은 12/1 AI툴 지원금(200,000원) 입금 후 회복됩니다.** 들어오면 예비비는 약 26~30만 원(Pro 함 262,800원 · 안 함 302,700원)이 됩니다. Retro Diffusion을 사면(조건부, 약 72,000원) 약 19~23만 원입니다.
- **예정(결제 전, 2장) 반영 시(11/27):** 그래픽 도구 70,000 → 51,000원, 베타 상품 60,000 → 상한 100,000원으로 바꾸면 예비비는 Supabase Pro 안 함 **81,700원** · 함 **41,800원**(AI툴 지원금 입금 후 281,700 · 241,800원)으로, 예정 금액은 예비비 안에 듭니다.
- AI툴 지원금이 들어오기 전(11/26~12/1)에는 예비비가 6~10만 원대입니다. 이 기간에는 2장 표에 없는 결제를 하지 않습니다.
- 예비비는 **장애·긴급 대응에만** 씁니다(예: 발표 직전 Claude 한도 초과로 추가 사용량 구매, 베타 중 Supabase 한도 초과). 새 기능용 유료 도구는 사지 않습니다(12/3 밤 기능 동결).

## 4. 항목별 결제 방법

### 4-1. Claude 구독 (11/26, 오늘)
1. **결제는 각자 자기 계정에서 합니다.** 계정·카드 공유는 하지 않습니다(한 계정을 여럿이 쓰면 이용 약관 위반이고 사용량 한도도 같이 깎임).
   - 종헌: 자기 계정을 Max(5x)로 업그레이드.
   - 중혁·현규: 각자 계정을 Pro로 업그레이드하고, **결제 화면(금액·날짜) 캡처를 종헌에게 보냄 → 종헌이 개발지원비에서 같은 금액을 바로 이체**. 캡처에서 카드 번호는 가립니다.
2. **결제 직후 자동 갱신을 꺼 둡니다**(설정 → 구독 → 취소). 취소해도 남은 기간(약 12/26까지)은 그대로 쓸 수 있고, 잊어서 12/26에 두 번째 달이 결제되는 일을 막습니다. 대회 뒤 계속 쓰고 싶은 사람은 자기 돈으로 다시 켭니다.
3. 결제 내역을 5장 장부에 적습니다.

### 4-2. NCP 크레딧 (등록 완료, 쓰는 방법)
- **이미 메인 계정에 등록·적용 중**입니다(11/1부터 CLOVA 사용료 2,020원이 크레딧에서 빠짐). 따로 할 일 없음.
- 지금까지 쓴 속도(25일에 2,020원)면 12/31까지 크레딧의 1%도 쓰지 않습니다.
  - **eval 규칙(11/26 종헌 결정):** 크레딧 등록 완료(11/26, 잔액 497,980원, 12/31 만료). CLOVA Studio 호출(리랭커·검증 호출·더 큰 모델 비교 포함)은 크레딧으로 쓰므로 비용 때문에 줄이지 않는다. 판단 기준은 정답률과 평균 응답 4초. eval 실행 횟수 제한 없음. 단 숨긴 문항(hidden)은 단계 PR의 최종 판단 때만 돌리고, 연속 실행으로 429가 나면 문항 사이에 간격을 둔다. 기준선 비교·실서비스 eval 결과는 PR이나 STATUS에 결과 파일·정답 수를 기록하고, 밤 점검 때 크레딧 잔액을 같이 적는다. 하루 크레딧이 1만 원 넘게 줄면 단톡에 한 줄 공유한다(허락 필요 없음). 사용자당 호출·입력 길이 제한은 남용 방어라 그대로 둔다.
  - **검색창 전체 하루 상한(`ASK_LIMITS.globalDay`)은 11/27 500 → 2000**(PM 결정: 이종헌. NCP 크레딧 사용 원칙 + 베타 20명×하루 50 기준, eval 요청은 전체 한도에서 뺌). 비용 이상은 NCP 예산 알림으로 감시. 베타(12/4)·발표일(12/9)에 로그(`reason: global`)로 찼는지 보고, 더 올려야 하면 코드 설정 변경이므로 PR로 하고 동결 예외로 기록(종헌 결정 필요).
- **Budgets 알림(50만 원)은 크레딧 공제 뒤 금액 기준이라 0%로 보일 수 있습니다.** 매일 밤 점검(OPERATIONS 3장)에서 **크레딧 잔액**을 같이 적습니다. 하루에 1만 원 넘게 줄면 단톡에 한 줄 공유합니다(허락 필요 없음, 지금 속도의 100배 이상).
- 크레딧이 적용되지 않는 NCP 상품(유료 Object Storage 등)은 쓰지 않습니다. 새 NCP 상품을 켜기 전에 크레딧 상세의 "적용 상품"을 먼저 확인합니다.
