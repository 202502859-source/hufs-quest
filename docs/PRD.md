## 1. 문제 정의 한 문장

> **서울캠퍼스 1~2학년 재학생**이 **이중전공·전과·졸업학점 같은 학사 제도를 처음 알아봐야 할 때**,
> 규정이 하위 사이트 57곳·링크 771개에 흩어져 있어 **어디서 무엇을 봐야 할지 몰라 기준을 놓치거나 잘못 안다.**
> HUFS Quest를 쓰면 **검색창 한 번으로 공식 문서 근거와 원문 링크를 받고**, 캠퍼스를 걷다 만나는 퀘스트로 **몰랐던 제도를 미리 알게 된다.**

### 이번 대회의 '한 사람'

| 항목 | 내용 |
| --- | --- |
| 누구 | 서울캠퍼스 1~2학년 재학생. 이중전공을 할지, 어떤 기준이 적용되는지 고민 중 |
| 언제 | 이중전공·전과 신청 전, 수강신청 전, 학기 초 |
| 무엇이 불편 | 같은 제도의 소개·일정·신청 시스템·배정 기준이 다른 페이지에 있고, 학번·캠퍼스마다 기준이 다름 |
| 쓰고 나면 | 내 학번 기준 숫자 + 원문 링크를 1분 안에 확인. 마감 임박 신청을 D-day로 봄 |

발표·시연·베타테스트·질문표는 모두 이 한 사람을 기준으로 만듭니다.
게스트(외부인) 모드는 이미 만들어져 있어 그대로 두지만, **수험생·주민·유학생·교직원을 위한 새 기능은 만들지 않습니다.**

| --- | --- | --- |

| 🔴 반드시 | 검색창 비용·남용 방어 | 서버에서 IP당 1분 횟수 · 하루 횟수 · 전체 하루 상한 · 입력 길이 제한이 **여러 서버 인스턴스에서도** 동작. NCP 예산 알림 설정 |
| 🔴 반드시 | 학교 이메일 로그인 · 진행 저장 | 진짜 메일로 로그인 → 경험치가 서버에 저장. A 계정으로 B 계정 기록이 안 보임. 개인정보 안내 문구(항목·목적·보관 기간) 표시 |
| 🔴 반드시 | 마감 임박 공지 실제 반영 | `[예시]` 0건, 팀이 직접 확인한 실제 공지 10건 이상, 모두 원문 링크 |
| 🔴 반드시 | 시연 동선 맵 그래픽 · 맵 현행화 | 시연 동선 건물 그래픽 교체, 건물 정보는 데이터 파일로 분리, 화면에 맵 기준일과 "실제와 달라요" 신고 버튼 |
| 🟡 가능하면 | 퀴즈 확장 | 새 근거 문서로 문항 추가, 문항마다 출처 링크, 깨진 링크 0 |
| 🟡 가능하면 | 복합 질문 나눠 찾기 (Advanced RAG) | 질문 하나를 최대 2개 하위 질문으로 나눠 각각 문서 검색. 복합 질문 묶음 정답률이 오르고 기존 정답률은 유지될 때만 반영 |

## 3. 하지 않을 것 (대회 기간 11/16~12/9)

| 하지 않을 것 | 이유 · 대신 하는 것 |
| --- | --- |
| 건물 내부 진입(Tiled 실내 맵) | 피드백 권고. 현행화할 곳이 크게 늘고 이종헌에게 일이 몰림. 발표에서는 '다음 단계'로만 소개 |
| 교내 행사 실시간 반영 · 학생회 행사 등록 폼 | 피드백 권고. 등록 권한·XSS 같은 새 허점이 생김. 발표에서는 '다음 단계'로만 소개 |
| 과제 일정 직접 등록 | 저장 위치·개인정보 설계가 없음. 만들지 않음 |
| 한국어·영어 밖의 언어(제3언어) | HyperCLOVA X 성능 보장 범위 밖. 한국어·영어만 유지 |
| 학사정보시스템 Open API 실제 연동 | 학교 승인 절차가 3주 안에 끝나기 어려움. 대회 기간에는 **문의만** 하고, 문서마다 수집일·적용 기준을 저장해 낡은 답을 막음 |
| 공지 게시판 자동 수집(크롤링) | 학교 robots.txt와 규정. 공지는 팀이 손으로 입력 |
| 리워드 교환 · 상용화 | 기획서에서 '향후'로 미룸 |
| 수강신청 추천 · 모의 수강신청 | 기획서(11/10)에서 제외. 본선 화면에서 버튼을 숨김 |
| NCP Maps 연동 | 사용은 가능하다는 답을 받았지만 이번 범위의 문제를 풀지 않음. 맵 그림 참고 자료로만 씀 |
| 유료 서비스 결제 (11/25 전) | 예산 지급이 11/25쯤. 그 전에는 무료 플랜 · 무료 도구로만 작업 |

## 4. 사용자 흐름 (시연 기준)

1. 타이틀 → 재학생 로그인(학교 메일 6자리 코드) → 개인정보 안내 확인
2. 정문에서 출발, 화면 상단 검색창에 "25학번 이중전공 기준 학점 몇이야?" → 답 + 근거 번호 + 원문 링크 + "2026-11 수집 기준"
3. 맵을 걸으며 퀘스트(목적지는 건물 ID로 연결) → O/X 퀴즈 → 경험치 서버 저장
4. 오른쪽 위 ! → 마감 임박 공지 D-day 순 목록 → 원문 링크
5. 맵 한쪽의 "2026년 11월 기준 캠퍼스" 표시와 "실제와 달라요" 신고 버튼 소개

## 5. 판단 기준

- 새 아이디어는 1장의 '한 사람'에게 도움이 되는지, 2장 완성 기준을 올리는지로 판단합니다.
- AI 기능은 "좋아진 것 같다"가 아니라 질문표 정답률로 판단합니다. 떨어지면 되돌립니다.
- 12/2(수) 기능 동결 이후에는 이 문서의 표를 늘리지 않습니다.
